# Projet ENT - Espace Numérique de Travail

## Architecture Microservices
- **MS Auth** : Authentification (M1) - Port 8001
- **MS Upload** : Upload cours (M2) - Port 8002
- **MS Download** : Téléchargement cours (M3) - Port 8003
- **MS Chatbot** : IA et Admin (M4) - Port 8004
- **Frontend** : React - Port 3000

## Technologies
- Backend: FastAPI (Python)
- Frontend: Reactjs
- Base: Cassandra
- Storage: MinIO
- Auth: Keycloak
- IA: Ollama + Llama3
